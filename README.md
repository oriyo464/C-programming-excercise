#include <stdio.h>: Includes standard input/output declarations so we can use functions like printf().  
 int main(void): Defines the main function where program execution begins.   
 printf(): Displays output 
 \n: Moves the cursor to a new line.  
  return 0;: Ends the program and reports successful completion. 
;: Terminates a C statement (leaving this out will cause a compilation error).
